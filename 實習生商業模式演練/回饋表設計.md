# 實習生商業模式演練｜第 1 輪 訂閱制：回饋表設計

目的：給每位實習生個人化的回饋。正職不打分數，改選「最強」「最需加強」各一項並附文字；實習生保留自評分數，另寫同儕觀察。

實際使用的是兩份 Google 試算表（分開是為了讓實習生看不到正職的個別回饋）：

- 實習生自評與同儕觀察：分享給實習生
- 正職回饋與對照：只分享給正職，內含自動彙整的「對照彙整」分頁

## 表 A：實習生自評（約 4 分鐘）

| 欄位 | 填法 |
|---|---|
| 姓名、組別 | 姓名已預填；組別下拉選 A 組／B 組 |
| 四構面自評 | 九宮格完整度、資料佐證、洞察觀點、表達簡報，各填 1–5 的整數 |
| 我覺得自己最強的一項 | 下拉選四構面之一 |
| 我覺得自己最弱的一項 | 下拉選四構面之一 |
| 我負責的部分 | 哪幾格、哪幾頁 |
| 本輪盲點 | QA 時被問倒或沒想到的地方 |
| 需要幫忙的地方 | 勾選：找資料／判斷可信度、收益與成本推估、九宮格各格的邏輯、簡報取捨、QA 應答、請教熟悉校友的同仁；另有其他需求欄 |

## 同儕觀察（約 2 分鐘）

每位實習生對另外 3 位各寫一列：

| 欄位 | 填法 |
|---|---|
| 觀察者、被觀察的實習生 | 已預填 |
| 值得我學習的一點 | 寫具體的行為或做法 |

## 表 B：正職回饋（約 4 分鐘）

每位正職對每位實習生各填一列，不打分數：

| 欄位 | 填法 |
|---|---|
| 評分者、實習生 | 已預填；名單外的人填在下方空白列 |
| 最強的一項 | 下拉選四構面之一 |
| 具體觀察 | 為什麼選這一項，寫具體內容 |
| 最需加強的一項 | 下拉選四構面之一 |
| 建議做法 | 下一輪可以怎麼改 |
| 外部研究看不到的資訊 | 選填，熟悉該校友的同仁補充 |
| 今天最好的提問 | 選填 |

## 對照彙整（自動計算）

每位實習生一列：自評分數、自評最強與最弱、正職選為最強與最需加強的人數、正職最多人選的最需加強、「最弱的看法」是否一致（不一致標橘色）、需要幫忙的地方，以及正職觀察、正職建議、同儕值得學習的一點三欄文字彙整。

## 四個構面的判斷標準

| 構面 | 2 分 | 3 分 | 5 分 |
|---|---|---|---|
| 九宮格完整度 | 有格子沒填，或內容放錯格 | 九格齊全，但各格之間沒有串起來 | 黃金三角（客群、價值、收益）說得通，其他格都能支撐它 |
| 資料佐證 | 大多是臆測 | 有官網資料，但關鍵數字沒有出處 | 官網和內部雲端資料交叉驗證，分清楚事實與推估 |
| 洞察觀點 | 只是描述這家公司做什麼 | 有指出訂閱制的特徵 | 說得出這家公司訂閱制的成功關鍵和風險 |
| 表達簡報 | 超時，重點不清楚 | 時間內講完，但取捨不夠 | 5 分鐘內講到重點，QA 回應精準 |
